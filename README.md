# DCHM Generator

Digital Canopy Height Model (DCHM) 生成プラグイン for QGIS

## 概要

DCHM Generatorは、Digital Surface Model (DSM) と Digital Terrain Model (DTM) から、樹冠高モデル (Canopy Height Model / CHM) を生成するQGISプラグインです。

ドローン写真測量により取得したDSM/DTMの対地高をそのまま出力するのではなく、**林床高（地表面）に対する樹木の相対的な高さ（樹冠高）** を算出します。林業・森林調査などの用途で活用できます。

## 主な特徴

### ✨ 高精度な処理

- **スマート外れ値補正**: 樹頂点などの自然な鋭いピークを保持しながら、計測外れ値のみ除去
- **面補正 (Trend Surface Correction)**: 露出点を用いたトレンド面補正により、計測機材による系統的な誤差を補正
- **二重リサンプル防止**: 目的CRSへの再投影とグリッド整列を **1回のWarpで同時に実行**
  - QGIS側で事前に再投影すると画質が劣化する問題を根本解決

### 🎯 柔軟な設定

- **複数のCRS対応**: 日本の平面直角座標系（JGD2011/JGD2000）に対応
  - ドロップダウンメニューで一般的なEPSGコードから選択
  - 任意のEPSGコードも直接入力可能
- **解像度指定**: 出力の地上解像度（GSD）を自由に設定
- **スパイク除去の微調整**: 閾値と評価窓を細かく設定可能

### 🚀 ユーザーフレンドリー

- **プロジェクトへの自動追加**: 生成完了後、そのままプロジェクトに追加できるオプション
- 直感的なUI：レイヤ選択とパラメータを簡潔に配置

## インストール

### 前提条件

- QGIS 3.0 以上
- Python パッケージ:
  - `numpy`
  - `scipy`
  - GDAL/OGR

### インストール手順

1. プラグインディレクトリに `DCHM_Generator` フォルダをコピー
   ```
   ~/.qgis2/python/plugins/DCHM_Generator/
   # または Windows の場合:
   C:\Users\[ユーザー名]\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\DCHM_Generator\
   ```

2. QGIS を起動し、「プラグイン」→「プラグインの管理」から「DCHM生成」を有効化

## 使い方

### 基本操作

1. **プラグインを起動**
   - QGIS のツールバーから「DCHM生成」ボタンをクリック

2. **入力レイヤを選択**
   - **DSMレイヤ**: ドローン計測による Digital Surface Model（対地高データ）
   - **DTMレイヤ**: 同じエリアの Digital Terrain Model（林床高データ）
   - **露出点レイヤ** (オプション): 面補正用の検証点（ポイントレイヤ）

3. **パラメータを設定**
   - **スパイク除去**: 計測外れ値を補正するか選択（推奨：有効）
   - **スパイク閾値**: 外れ値と判定する高さ差(m) ※樹頂点は保持
   - **スパイク窓サイズ**: 中央値フィルタの評価範囲(m)
   - **出力解像度**: 出力ラスタのGSD(m)
   - **出力先CRS**: 結果を出力するCRS（EPSGコード）

4. **出力ファイルを指定**
   - GeoTIFFファイルの保存先を選択

5. **「DCHMを生成」をクリック**
   - 処理が実行されます

### 重要な注意点 ⚠️

#### 施業前後での比較

同じ現場の施業前後を比較する場合、**必ず同じ出力解像度を使用してください**。異なる解像度で生成した場合、単純な差分計算では正確な材積推定ができません。

```
施業前: 0.1m 解像度で生成 ✓
施業後: 0.1m 解像度で生成 ✓
（同じ解像度なら安全に比較可能）
```

#### 元データの利用

- ドローン写真測量ソフト（Metashape, PIX4D など）の **生出力** をそのまま読み込んでください
- QGIS で事前に再投影すると、このプラグイン内での Warp と合わせて **2回リサンプルされ、樹冠ピークの画質が劣化**します

#### CRS指定

出力先CRSは平面直角座標系（日本）を想定していますが、以下から自由に選択可能：
- **JGD2011 系**: EPSG:6676～6685（Ⅸ～Ⅹ VIII 地域）
- **JGD2000 系**: EPSG:2443～2450（EPSG:2443～2446 など）
- その他: 任意の EPSG コード入力も可能

## パラメータ解説

| パラメータ | 用途 | 推奨値 | 備考 |
|-----------|------|-------|------|
| スパイク閾値 | 外れ値と判定する高さ差(m) | 3.0～5.0 | 値が大きいほど樹頂点を保持 |
| スパイク窓サイズ | 中央値フィルタの評価範囲(m) | 0.5～1.0 | 物理サイズで指定（解像度に依らず） |
| 出力解像度 | ラスタのGSD(m) | 0.1～0.5 | 施業前後で統一すること |

---

## 処理フロー

```
DSM, DTM (元のCRS)
     ↓
  [スパイク除去] ← 外れ値のみ補正、樹頂点保持
     ↓
[目的CRSへWarp] ← 再投影 + グリッド整列 (1回のみ)
     ↓
[面補正計算]   ← 露出点を用いたトレンド面補正
     ↓
  DCHM = DSM - DTM - 補正量
     ↓
[GeoTIFF保存]
     ↓
[プロジェクト追加] (オプション)
```

## 出力ファイル仕様

- **形式**: GeoTIFF (.tif)
- **データ型**: Float32
- **CRS**: ユーザー指定のCRS
- **NoData 値**: -9999.0
- **座標原点**: 絶対グリッドに整列（サブピクセル誤差なし）

## トラブルシューティング

### ❌ エラー: "DSMまたはDTMラスタを開けませんでした"

**原因**: GDALが入力ファイルを読み込めない
- ファイルパスに特殊文字が含まれていないか確認
- ラスタファイルの形式・圧縮方式を確認
- GDALで直接読込テスト: `gdalinfo` コマンドで確認

### ❌ エラー: "DSMとDTMに重複する範囲がありません"

**原因**: DSMとDTMの対応する領域がない
- DSMとDTMが同じエリアをカバーしているか確認
- CRSが異なる場合、座標系を確認

### ❌ CRS指定エラー: "CRS指定が不正です"

**原因**: EPSGコードが無効または登録されていない
- EPSG コードが正しいか確認（例: `EPSG:6676`）
- [EPSG.io](https://epsg.io) で検索可能
